# 赛博包青天

**开源招录公示检索与提醒工具，自动汇集指定时间范围内的官方公示链接。**

代码基于 [MIT 许可证](LICENSE) 开源，欢迎使用、收藏（Star）和参与更新。

源码地址：https://github.com/youdera/cyber-baoqingtian

## 能做什么

- 公示发布时间与考试／招考年份可分别查询，也可组合；只填一端即查该月或该年。至少选择一种时间，未知年度单列待核对。
- 默认省内招录，选择省份；全国／中央招录单独选择。查询读取本机索引，“检查官网更新”触发采集。
- 保存关注，设置本机每日固定时间或6/12/24小时间隔检查，新发现或元数据更新时产生提醒。
- 爬虫批量巡检固定官方来源目录，检查可访问性、发现门户内的候选招录栏目，记录具体失败原因。
- GitHub Actions每天北京时间09:17检查已接入公告栏目；每周日09:37巡检来源目录，也支持手动运行。

## 来源范围

当前登记76个入口：18个正式公告栏目，以及58个候选栏目和导航门户。部分门户已接入其下的具体栏目，其余范围继续核验。**登记不等于接入，网站可访问不等于公示完整覆盖。**

正式索引包括中央统计局1个栏目、北京2个、福建2个、广东4个、山西3个、四川6个。本轮新增四川公务员及事业单位六类、山西考试与省直招聘三类、肇庆两类与阳江公务员栏目。

四川选调生的首页与后续页总数不一致；肇庆、阳江接口可列出数量少于栏目计数，外部跳转条目不纳入。以上来源保留具体历史缺口；广东省厅200页上限和福建历史未接入的限制仍存在。各省市栏目都不能代表当地所有单位。[本轮接入与验收](docs/SOURCE_INTEGRATION_20260912.md)

同一官方URL被多个栏目收录时只保存一份公告，分别保留各栏目元数据；查询可按栏目筛选，合并结果显示匹配来源。目录出现重复页、错误栏目或结构变化会明确报告，不能当作已查完。

门户巡检只读取登记首页、识别候选栏目链接；不会自动把未验证的新网址加入正式采集，也不下载或索引人员名单。具体核验结果及缺口见[来源覆盖](docs/SOURCE_COVERAGE.md)。

## 时间怎么选

| 想查的范围 | 填写方式 |
|---|---|
| 2026年发布的公示 | 公示时间2026-01至2026-12，考试年份不限 |
| 2025年度考试的公示，可能跨年发布 | 只填考试年份2025 |
| 2025年度考试、2026年发布 | 同时设置以上两项，取交集 |
| 某一个月份 | 只填该月份，另一端自动补齐 |

考试年份从标题保守识别，不使用发布日期代替。多年份或毕业年份等歧义显示待核对；参与筛选的字段存在未知信息时单列待核对。

## 本地启动

安装Python 3.10+，Windows双击start.cmd；或安装requirements.txt后运行：

```text
python notice_app.py --open
```

浏览器打开http://127.0.0.1:8765/。在“来源与覆盖”点击“巡检全部登记入口”。本机定时需要程序保持运行；浏览器通知需主动授权并保持网页打开。

## GitHub定时与提醒

云端范围由cloud-watch.json控制，初始为2026年发布的录聘公示及更正撤销。网站保存的关注条件不会自动同步到GitHub。

新发现、元数据变更或来源状态变化会创建Issue并指派仓库所有者。首次运行和新增来源分别建立基线，不逐条推送已有历史；已有来源正常更新继续提醒，首次访问失败的来源在恢复后再建基线。邮件和手机通知取决于GitHub设置。来源巡检报告保存在Actions摘要和artifact中。缓存不是永久档案，定时可能延迟。详见[使用说明](docs/CLOUD_WATCH.md)。

仓库公开的是代码、说明及官方公告元数据报告；本机历史数据、个人材料和旧版兼容模块不在独立发布快照中。GitHub仓库公开不等于提供在线运行的网站。

欢迎提交官方来源入口、适配器修复和脱敏测试，也欢迎通过Issue反馈失效栏目。新增来源请附官方归属依据，说明目录、分页与历史缺口，不用站点数量宣称全国完整覆盖。
