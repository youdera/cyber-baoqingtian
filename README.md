# 赛博包青天

**开源招录公示检索与提醒工具，自动汇集指定时间范围内的官方公示链接。**

代码基于 [MIT 许可证](LICENSE) 开源，欢迎使用、收藏（Star）和参与更新。

源码地址：https://github.com/youdera/cyber-baoqingtian

## 能做什么

- 按公告发布起止年月、可选招考年度、地区、招录类型和发布栏目查询官方公告链接。
- 保存关注，设置本机每日固定时间或6/12/24小时间隔检查，新发现或元数据更新时产生提醒。
- 爬虫批量巡检固定官方来源目录，检查可访问性、发现门户内的候选招录栏目，记录具体失败原因。
- GitHub Actions每天北京时间09:17检查已接入公告栏目；每周日09:37巡检来源目录，也支持手动运行。

## 来源范围

当前登记63个入口：3个正式公告适配器、7个候选栏目、53个从广东人社厅官方导航整理并核对的门户入口。**登记不等于接入，网站可访问不等于公示完整覆盖。**

正式索引目前包括国家统计局公务员招录、福建科技厅招考招录、广东人社厅事业单位公开招聘。广东已实测200页1783条元数据，达到官网页数上限，状态为部分未查完。福建历史分页未接入。

门户巡检只读取登记首页、识别候选栏目链接；不会自动把未验证的新网址加入正式采集，也不下载或索引人员名单。具体核验结果及缺口见[来源覆盖](docs/SOURCE_COVERAGE.md)。

## 本地启动

安装Python 3.10+，Windows双击start.cmd；或安装requirements.txt后运行：

```text
python notice_app.py --open
```

浏览器打开http://127.0.0.1:8765/。在“来源与覆盖”点击“巡检全部登记入口”。本机定时需要程序保持运行；浏览器通知需主动授权并保持网页打开。

## GitHub定时与提醒

云端范围由cloud-watch.json控制，初始为2026年发布的录聘公示及更正撤销。网站保存的关注条件不会自动同步到GitHub。

新发现、元数据变更或来源状态变化会创建Issue并指派仓库所有者。首次运行建立基线；邮件和手机通知取决于GitHub设置。来源巡检报告保存在Actions摘要和artifact中。缓存不是永久档案，定时可能延迟。详见[使用说明](docs/CLOUD_WATCH.md)。

仓库公开的是代码、说明及官方公告元数据报告；本机历史数据、个人材料和旧版兼容模块不在独立发布快照中。GitHub仓库公开不等于提供在线运行的网站。

## 参与更新

欢迎提交官方来源入口、适配器修复和脱敏测试，也欢迎通过Issue反馈失效栏目。新增来源请附官方归属依据，说明目录、分页与历史缺口，不用站点数量宣称全国完整覆盖。
