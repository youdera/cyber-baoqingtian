# 0.2 公告浏览与更新提醒

当前入口为notice_app.py。start.cmd/start.ps1及本机python app.py命令进入新版；不挂载旧姓名匹配API。旧数据留在本机，新版不自动迁移。

## 当前能力

- 公告发布起止年月必填，包含首尾日；招考起止年度可选。
- 按地区、类型、发布栏目及公示范围筛选，未知信息单列待核对。
- 只索引公告标题、日期、官方链接、来源等元数据；不下载名单附件，不关联人员身份。
- 保存关注、每天北京时间固定时刻或6/12/24小时间隔检查、暂停恢复。
- 新发现或元数据变更产生站内提醒；可标已读。浏览器通知需要主动授权且页面打开。
- 本机程序关闭期间不运行；启动后合并补查到期任务。
- GitHub定时配置与本地条件独立，详见[CLOUD_WATCH.md](CLOUD_WATCH.md)。配置存在不代表云端已成功运行。

## 来源与覆盖

接入统计局公务员招录、福建科技厅招考招录、广东人社厅事业单位公开招聘三个栏目。广东为本轮新增，适配公告URL与目录分页。

福建仅读当前页；广东官网最多提供200页，记录总数超出该范围时保持partial。栏目读取完成也只指该栏目，不表示全省、全国或全年完整。更多已探测入口及具体失败原因见[SOURCE_COVERAGE.md](SOURCE_COVERAGE.md)，实际采集结果见HANDOFF.md最新日志。

来源固定在代码中；逐跳校验官方HTTPS域名、robots、TLS及DNS，不绕过访问限制。当前VPN的198.18.0.0/15虚拟DNS兼容仅适用于固定官方域名。
