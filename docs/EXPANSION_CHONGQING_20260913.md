## 元数据边界

目录确实夹带大段公告正文。探测及验收均只在内存中处理页面，**没有持久化 raw HTML、正文或名单附件**。最终实现先取得目录锚点的唯一直属 `.content-view`，再只取该节点直属的 `.title`、`.date`，以及锚点链接。缺少真正目录标题即报错，不回退到整段锚点文本、锚点 `title` 属性或正文中的同名节点。新增脱敏回归分别验证：正文嵌套同名节点不能替代缺失标题；真实标题存在时，正文同名节点不影响标题与日期。

目录发布日期独立解析，不使用正文中的公示期、URL、考试年份补日期。未知日期保留为空。同域网页路径限定为七一网已核验的 `/web/article/[ID/]web/content_ID.html` 结构；同域附件、外域 URL 都排除。

地区统一按**发布来源**记为重庆，不表示岗位所在地。两个来源的 `kind=''`，让混合栏目在按国考、省考或事业单位筛选采集时都能进入检查；条目类别由 `chongqing_kind(title)` 判断。明确编外、非编、编制外、非在编、劳务派遣或国企的条目保留未知；公务员、参公优先按公务员类别判断；明确事业单位或事业编制才标为事业单位，不能仅凭“公开招聘”认定；其余按这两个公务员栏目的默认类别省考处理。明确中央机关、国考的标题标为国考，仍保留重庆发布来源。全国/中央范围继续按独立中央发布来源隔离，七一网转载仍属于省份来源。

分页参数来自官网内嵌 JSON `var data = {pages,current,href,total}`，不执行 JavaScript。`href` 数组包含可选上一页、全部页码、可选下一页，因此数组长度随首页、中间页、末页变化。适配器核对返回页码、栏目 ID、每个固定同域分页地址；页码不一致和外域分页地址会被拒绝，相同条目的重复页由主引擎另行检测。

## 复核与修复记录（2026-09-13）

首先只读核对适配器、脱敏夹具和已有目录汇总。来源/附件过滤与记录计数一致；50 页窗口、外域排除和其他原站 403 缺口已有明确说明。

发现并离线重现了两个问题：原后代选择器可能在真正标题节点缺失时匹配正文中的嵌套同名节点；原来源 `kind=省考` 会让国考筛选在采集前跳过该混合栏目，而国考条目 `region=''` 又会在重庆筛选中进入待核对。获主任务授权后，已将节点选择改为逐级直属范围，将来源类别改为空，条目地区统一为重庆发布来源，并增加类型与筛选回归。12 项测试通过；只修改重庆模块、测试和本报告，没有重新采集或修改数据库、核心、网络设置。
