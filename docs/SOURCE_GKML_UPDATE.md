# 2026-09-12 广东公开目录适配与核验

本轮新增肇庆人社局两个栏目、阳江人社局一个栏目。实现位于 `wuzhong/gkml_sources.py`，只解析公开目录 JSON，不请求公告详情或人员附件。开工和每轮联网核验前均读取 `HANDOFF.md`；请求统一使用现有 `Fetcher`，保留 HTTPS、robots、证书验证、同主机限制、超时及至少两秒间隔。

GitHub 研究只提供了 gkmlpt 模板线索。本轮根据官网公开栏目配置和实际加载脚本独立实现，没有复制未提供许可证的第三方源码，也没有安装或执行第三方爬虫。

## 官方结构证据

栏目网页公开的 `window._CONFIG` 包含 `APP_URL`、`SID` 和 `TREE`。本轮只用其中的站点与栏目元数据，不保存页面正文或其他配置。实际目录服务以部门前缀构造，不能只按主机名猜 `/gkmlpt/` 的根路径：

- [肇庆事业单位目录第一页](https://www.zhaoqing.gov.cn/zqrsj/gkmlpt/api/all/21206?page=1&sid=758017)、[第二页](https://www.zhaoqing.gov.cn/zqrsj/gkmlpt/api/all/21206?page=2&sid=758017)、[第三页](https://www.zhaoqing.gov.cn/zqrsj/gkmlpt/api/all/21206?page=3&sid=758017)。
- [肇庆公务员目录](https://www.zhaoqing.gov.cn/zqrsj/gkmlpt/api/all/22168?page=1&sid=758017)。
- [阳江公务员目录](https://www.yangjiang.gov.cn/yjrsj/gkmlpt/api/all/318?page=1&sid=662018)。
- [肇庆公开目录加载脚本](https://www.zhaoqing.gov.cn/gkmlpt/gkml/pc/js/chunk-common.c1553651.js)、[阳江同版公开脚本](https://www.yangjiang.gov.cn/gkmlpt/gkml/pc/js/chunk-common.c1553651.js)。

脚本显示，网页每次展示 20 条，接口以 5 个展示页合为一组，因此一个完整 JSON 页为 100 条。响应包含 `articles`、`offset`、`total`、`classify`；适配器校验请求页码、SID、栏目 ID/名称、偏移量及原始条目数。下一页根据接口原始条目数计算，不能用过滤后的 97 条等数值判断是否结束。

肇庆事业单位第三接口页返回 `offset=200, total=221, articles=21`，适配器停止于第三页。研究阶段额外核对第四页返回 404；两个单页公务员栏目第二页也返回 404。运行中的爬虫不会为了探测终点继续请求这些不存在的页。分页结束仅证明当前目录窗口已遍历，不证明历史齐全。公开网页分页脚本还将显示总数限制在 10,000；本项目设置 100 个 JSON 页上限，若未来仍有下一页则保留“达到分页上限”。

## 日期与原文链接

**公告发布日期取 `create_time`，不用 `date` 或 `created_at` 替代。** 官方脚本表头顺序是“名称、发布日期、成文日期、文号”，对应字段为 `title/create_time/date/document_number`。`create_time` 为 Unix 秒时间戳，本项目固定按北京时间转换为日期。字段缺失、非法或为零时保持未知，不能拿成文日期、入库时间、URL 日期或考试年度补出。此次肇庆公务员存在 `created_at` 与显示发布日期不在同一天的记录，已按网页显示字段处理。

招考年度继续只由公告标题的明确年度提取，与公示发布时间独立；没有明确证据则进入待核对。

同域普通条目只接受已核验部门目录中的标准 `post_ID.html` 原文链接，并校验 ID、路径和主机。阳江 JSON 的部分普通原文链接写为 HTTP；官方加载脚本对普通条目改成协议相对链接，在 HTTPS 栏目中呈现为 HTTPS。本项目依同样规则规范化为同域 HTTPS，不跟随重定向、不访问详情，也不据此宣称详情页已实测可用。

外部跳转类型 `type=url` 不收录，原因在来源说明中显示。肇庆事业单位的 4 条引用指向省级人社发布页面，公务员的 1 条指向省组织部门页面。当前公告库按 URL 标识且每条记录只有一个来源；直接混入引用可能覆盖原发布来源，因此本轮保持明确边界，未临时改变全库 ID 规则。未来若支持多来源归属，再单独验收跨站引用。
