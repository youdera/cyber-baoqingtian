## 已独立实现的四川适配

本次从[四川省人社厅官网首页](https://rst.sc.gov.cn/)实际读取到两处“人事考试”链接，均指向 `https://www.scpta.com.cn/`。考试站目录标题为“四川省人力资源和社会保障厅人事考试专栏”，页脚标明四川省人事考试中心。配置保留 `provenance=https://rst.sc.gov.cn/`；该域名是有官方主办关系证据的固定例外，不代表允许任意第三方域名。

RSSHub仅用于发现入口；下述解析根据官网实际HTML、栏目选中状态和分页参数独立实现，未复制上游AGPL代码。

`wuzhong/west_sources.py` 导出 `WEST_SOURCES`、`SOURCE_AREAS` 和 `parse_west(html, source, url)`。六个栏目分别登记，避免把 `/56` 的默认“公务员招考”误当成全部公务员类型，也避免把 `/67` 的默认“省属事业单位”误当成所有市州事业单位。

## 解析与失败处理

- 仅接收六个固定来源ID；请求必须保持指定HTTPS主机、栏目路径和 `t`、`a` 参数，`i` 为一基页码。
- 同时校验 `selId`、侧栏active栏目、响应页码、总记录数、每页条数及分页URL；错误栏目、首页重复回放、越界页码、结构变化不当作“零条公告”。
- 下一页只由官网 `pageUrl` 的已验证目录参数生成；每来源100页上限仍保留 `next_url`，由主引擎标记未完成。
- 每条仅提取目录中的标题、独立发布日期、官方链接及来源元数据；考试年度仍调用统一标题规则，与发布日期分别保存。
- 实测发现“特别提醒”等合法短标题，已允许非空短标题并加入回归测试；未知/无效日期保持未知，不拿URL或考试年份补发布日期。
- 只允许 `/front/News/info/<32位十六进制ID>?t=56或67` 对应栏目链接。任何未核验的详情格式、跨域、附件、附加参数或同页重复条目令当前页报错，防止静默漏掉异常条目后宣称完成。

`tests/test_west_sources.py` 包含10项脱敏测试，验证六个固定栏目、独立时间、首/次/末页、应用上限、短标题、日期未知、目录模板漂移、错误选中栏目、分页和公告链接限制、同页重复以及未知来源；本机运行通过。

## 主模块接线

1. 从 `west_sources` 导入上述来源及解析函数，将六个固定配置加入 `SOURCES`，将 `SOURCE_AREAS` 合并进现有范围映射。
2. `listing()` 对这六个ID分派到 `parse_west`，返回值与 `extra_sources` 相同。
3. 引擎必须保留来源 `history_note`；选调生可继续翻页，但即使到了第7页也保留 `partial`。
4. 来源目录/测试只对固定 `www.scpta.com.cn` 增加官方主办关系例外；来源示例检查亦要走 `parse_west`。
5. 真实入库、网页筛选验收、主文档覆盖数字和远端发布由主任务统一完成，本文件中的样本检查不替代这些步骤。
