## 浙江本轮未接入

- 浙江公务员入口 `https://gwy.zjks.gov.cn/zjgwy/website/init.htm`：现有 Fetcher 在读取该域名 `/robots.txt` 时发生 TLS 握手 `SSLEOFError / UNEXPECTED_EOF_WHILE_READING`，没有继续请求列表、详情或改用 HTTP。
- [浙江人社拟聘公示目录](https://rlsbt.zj.gov.cn/col/col1229743684/index.html)：页面可读取，显示“事业单位公开招聘 → 拟聘公示”，但列表由页面公开标记 `/api-gateway/jpaas-publish-server/front/page/build/unit` 与 `AuthorizedRead/unitbuild.js` 动态加载。读取页面引用的同域 `unitbuild.js` 时，Fetcher 阻止了离开当前官方域名的重定向。因此尚未验证公开目录请求参数、分页或历史，不登记为空来源，也不随意猜测 POST 请求。

上述是本机本轮访问结果，不表示这些站点永久不可用；后续可在官方访问条件允许并完成域名/模板核实后继续适配。本轮没有绕过限制或关闭 TLS。
